Date: 2026-11-19

## Authorized source

Owner requested publishing local changes as a version update. Baseline is
public v8.7.22; target is stable v8.7.23, GitHub Release and
`@seemseam/ccb@8.7.23` on npm. Prepared local commits are preserved:

- `cf3648dd9`: CCB-owned OMP display overlay disables inline images and
  rebuilds resize scrollback; no external Provider configuration is changed.
- `bb672a6aa`: synchronized version metadata and shorter README introductions.
- `c4c07aa59`: explicit Bun/OMP update discovery, installation-home binding,
  failed-probe handling and regression cases.
- `336a12997`: retained Android VM diagnosis and its production-incident limit.

All five originally dirty files were copied and fingerprinted into an isolated
release worktree. Publication does not run an actual external Provider update,
read credentials, or restart working agents. Bun upgrades remain behind the
existing explicit update consent flow; unknown owners remain report-only.
