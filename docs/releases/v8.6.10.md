# v8.6.10

Released: 2026-08-18

## English

### Highlights

- Managed Claude agents now refresh an existing Agent-private macOS Keychain
  credential when an external Claude OAuth re-login changes the inherited
  source authentication (Issue #319).

### Fixes and reliability

- A stopped managed restart compares the new source payload with the prior
  CCB-owned `.credentials.json` projection and updates only the matching
  Agent-derived Keychain service when the source changed.
- When the inherited source is unchanged, Claude's own refresh in the private
  service is preserved. External Claude Keychain services remain read-only.
- Symlinked CCB credential projections and private Keychain inspection errors
  fail closed. Deterministic regression coverage includes source re-login,
  private refresh preservation, symlink rejection, and inspection failure.

### Upgrade notes

- Restart existing managed Claude agents after upgrading to `v8.6.10`.
- No project, conversation, pairing, or configuration migration is required.

### Known limitations

- Real macOS Keychain qualification remains a platform-owner gate; this Linux
  build was verified with deterministic Keychain fakes and the full available
  regression suite.

## 中文

### 版本亮点

- 外部 Claude OAuth 重新登录后，受管 Claude Agent 会在源认证发生变化时
  刷新已有的 Agent 私有 macOS Keychain 凭据（Issue #319）。

### 修复与稳定性

- 受管重启会将新的源 payload 与上一轮 CCB-owned `.credentials.json` 投影
  比较；只有源发生变化时，才更新对应的 Agent 派生 Keychain service。
- 继承源未变化时，保留 Claude 在私有 service 中自行刷新的凭据。外部 Claude
  Keychain service 始终保持只读。
- CCB 凭据投影是 symlink，或私有 Keychain 检查出错时，会 fail closed。回归
  测试覆盖源重登录、私有刷新保留、symlink 拒绝和检查失败场景。

### 升级说明

- 升级到 `v8.6.10` 后，请重启现有受管 Claude Agent。
- 无需迁移项目、对话、配对或配置。

### 已知限制

- 真实 macOS Keychain 验证仍需平台维护者门禁；本次 Linux 构建已通过确定性
  Keychain fake 和当前完整回归测试。
