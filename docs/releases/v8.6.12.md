# v8.6.12

Released: 2026-09-02

## English

### Highlights

- CCB Mobile now exposes Pi and OMP native conversations while preserving
  Provider-private session paths, transcript boundaries, and token-aware
  projection.
- Managed Pi Agents inherit profile assets such as skills, prompt templates,
  themes, and packages through immutable shared snapshots into each
  Agent-private home (PR #328).

### Fixes and reliability

- Concurrent first starts now publish shared Provider snapshots atomically,
  avoiding partial cache state or replacement races.
- Managed Provider homes preserve Git author and committer identity without
  importing unrelated shell state (PR #330).
- An Agent turn now ends after an ask submission is accepted, returning
  control to the caller instead of waiting or polling (PR #329).
- The WeChat community group QR code and README cache keys are refreshed.

### Upgrade notes

- Restart managed Pi Agents after upgrading so their private homes receive the
  refreshed profile-asset projection. Existing conversations are retained.
- Update the CCB host and Android app together for the matching Mobile release.
  No project, conversation, pairing, or configuration migration is required.

### Known limitations

- Native Windows x64 and Herdr remain beta. Their artifact and contract gates
  are maintained by the isolated Windows release workflow; real user
  GUI/provider qualification remains separate.

## 中文

### 版本亮点

- CCB Mobile 现在可以显示 Pi 和 OMP 原生会话，同时保持 Provider 私有 session
  路径、transcript 边界和 token-aware 投影。
- 受管 Pi Agent 会通过不可变共享快照，将 skills、prompt templates、themes 和
  packages 等 profile 资产继承到各自的 Agent 私有 HOME（PR #328）。

### 修复与稳定性

- 并发首次启动现在会以原子方式发布共享 Provider 快照，避免出现不完整缓存
  状态或替换竞争。
- 受管 Provider HOME 会保留 Git author 和 committer 身份，同时不会继承无关
  shell 状态（PR #330）。
- ask 提交被接受后，Agent 当前 turn 会立即结束并把控制权交还调用方，不再等待
  或轮询（PR #329）。
- 已刷新微信社区群二维码和 README 缓存键。

### 升级说明

- 升级后请重启受管 Pi Agent，使其私有 HOME 获得更新后的 profile 资产投影；
  现有对话会继续保留。
- 请同时更新 CCB host 与 Android app，以使用匹配的 Mobile 版本。无需迁移项目、
  对话、配对或配置。

### 已知限制

- 原生 Windows x64 与 Herdr 仍处于 beta。其 artifact 和合同门禁由隔离的
  Windows release workflow 维护；真实用户 GUI/provider 验证仍需单独完成。
