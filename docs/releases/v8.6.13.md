# v8.6.13

Released: 2026-09-06

## English

### Highlights

- OMP asks now run in the visible managed pane and use OMP's native completion
  evidence.
- Config V1/V2 role selection now exposes only general roles and
  `agentroles.ccb_self`; workflow-specific `ccb_*` roles remain reserved for
  V3.

### Fixes and reliability

- Multi-tool OMP turns remain active after intermediate `tool_use` output and
  finish only on the final assistant result.
- Current public provider guidance now emphasizes the primary supported CLI
  families. DeepSeek CLI, Z.ai, and DeepSeek Harness remain implemented and
  retain their historical release notes, but are no longer presented as
  current headline support.

### Upgrade notes

- Restart managed OMP Agents after upgrading so active panes use the corrected
  ask and completion behavior.
- No project, conversation, or configuration migration is required.

### Known limitations

- Native Windows x64 and Herdr remain beta. Their artifact and contract gates
  are maintained by the isolated Windows release workflow; no Windows-only
  dependency is added to the shared Linux/macOS runtime by this release.

## 中文

### 版本亮点

- OMP ask 现在会在可见受管 pane 中运行，并使用 OMP 原生 completion 证据。
- Config V1/V2 角色选择现在仅显示通用角色和 `agentroles.ccb_self`；workflow
  专用 `ccb_*` 角色继续保留给 V3。

### 修复与稳定性

- OMP 多工具 turn 在中间 `tool_use` 输出后会继续保持活跃，只在最终 assistant
  结果出现时结束。
- 当前公开 Provider 指引改为重点展示主要支持的 CLI 系列。DeepSeek CLI、Z.ai
  和 DeepSeek Harness 的实现及历史 release notes 继续保留，但不再作为当前
  重点支持宣传。

### 升级说明

- 升级后请重启受管 OMP Agent，使活跃 pane 使用修正后的 ask 与 completion
  行为。
- 无需迁移项目、对话或配置。

### 已知限制

- 原生 Windows x64 与 Herdr 仍处于 beta。其 artifact 与合同门禁由隔离的
  Windows release workflow 维护；本版本不会向 Linux/macOS 共享运行时新增
  Windows 专属依赖。
