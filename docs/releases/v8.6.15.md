# v8.6.15

Released: 2026-09-06

## English

### Highlights

- CCB Mobile now displays OMP provider-native conversations as normal chat
  bubbles instead of showing an empty conversation.

### Fixes and reliability

- OMP is now included in provider-native conversation dispatch, transcript
  authority, and cache fingerprinting, so Mobile reads and refreshes the
  correct OMP session history.
- The shared Pi/OMP transcript reader now resolves session storage through
  `PathLayout.runtime_state_root`. This preserves V2 in-project runtime state
  while supporting V3 external runtime state.
- OMP transcripts may contain a title record before the session header. The
  reader now locates the session record, preserves its `session_id`, merges
  consecutive assistant text segments into one reply bubble, and keeps hidden
  thinking content out of the projected conversation.

### Validation

- The complete Mobile gateway test suite passed with 127 tests.
- Flutter static analysis completed without issues.
- Android API 35 end-to-end validation passed against a live V3 external
  runtime conversation in chat-bubble mode.

### Upgrade notes

- Upgrade both the CCB host and CCB Mobile APK, then restart the Mobile gateway
  so OMP transcript discovery and cache behavior are refreshed.
- No project, pairing, conversation, or configuration migration is required.

## 中文

### 版本亮点

- CCB Mobile 现在可以将 OMP 原生对话正常显示为聊天气泡，不再出现空白对话。

### 修复与稳定性

- OMP 已纳入 Provider 原生对话分派、记录权威判定和缓存指纹，因此 Mobile
  可以读取并及时刷新正确的 OMP session 历史。
- Pi/OMP 共用的对话读取器现在通过 `PathLayout.runtime_state_root` 定位 session
  存储，在保留 V2 项目内 runtime state 的同时支持 V3 外置 runtime state。
- OMP 对话记录可能在 session header 前包含 title 记录；读取器现在会主动定位
  session 记录、保留 `session_id`、把连续 assistant 文本片段合并为一个回复气泡，
  并确保隐藏的 thinking 内容不会进入投影后的对话。

### 验证

- 完整 Mobile gateway 测试套件共 127 项，全部通过。
- Flutter 静态分析通过，无问题。
- Android API 35 已针对 V3 外置 runtime 的真实对话完成聊天气泡模式端到端验证。

### 升级说明

- 请同时升级 CCB host 和 CCB Mobile APK，然后重启 Mobile gateway，以刷新 OMP
  对话发现和缓存行为。
- 无需迁移项目、配对、对话或配置。
