# v8.6.18

Released: 2026-09-17

## English

### Highlights

- Mobile now distinguishes working, idle, exception and unread Agent states
  across Agent/window selectors and project lists. Selection stays independent
  of activity; chat spacing is tighter without replacing the existing dual modes.
- Settings offers three offline background images, custom local images,
  previews and content opacity. Saved backgrounds survive app restart.

### Fixes and reliability

- Integrates #350 with additional local qualification: private macOS Keychains,
  one-way inherited Claude/AGY credentials, legacy Claude auth provenance
  migration and explicit-key OAuth-metadata isolation.
- Includes #353 and a compatibility correction: custom Codex endpoints bind
  available API keys through env_key without requiring keys for unauthenticated
  endpoints or enabling disabled environment inheritance.
- Claude managed API-key approval now includes explicit profile/Agent keys and
  permitted inherited credentials instead of relying only on managed settings.
  External Provider configuration and login state remain untouched.

### Upgrade notes and limitations

- Upgrade CCB and the Mobile APK to `v8.6.18`. Restart affected managed Agents
  when idle to regenerate private configuration. No manual pairing migration
  or changes to external Provider credentials are required.
- Mobile validation: 838 tests passed, 1 existing skip; final thumbnail styling
  passed 10 focused tests. Authentication follow-ups passed 380 related tests.
- macOS sleep/idle Keychain GUI behavior still requires native user retesting;
  Linux tests do not establish that acceptance. Windows remains beta with
  existing prerequisites. OpenAI-only endpoints do not become Claude-compatible.

## 中文

### 版本亮点

- 手机端在 Agent、窗口选择器和项目列表中区分工作中、空闲、异常及未读。
  选中状态与工作状态独立，对话间距更紧凑，保留原有对话/终端双模式。
- 设置中增加三款离线背景图片，保留本机自定义图片、预览和内容不透明度；
  已保存背景在应用重启后恢复。

### 修复与稳定性

- 整合 #350 并加入本地复核修正：macOS 私有 Keychain、Claude/AGY 凭据
  单向继承、旧版 Claude 认证来源迁移，以及显式密钥不继承 OAuth 账户元数据。
- 包含 #353 及兼容补丁：Codex 自定义端点通过 env_key 绑定可用密钥，
  不再为无鉴权端点强制要求密钥，也不绕过禁用环境继承的设置。
- Claude managed API Key 审批覆盖显式 profile/Agent 密钥和允许继承的凭据，
  不再仅依赖 managed settings；不修改外部 Provider 配置或登录状态。

### 升级说明与限制

- 将 CCB 和手机 APK 升级到 `v8.6.18`。相关 Agent 空闲后正常重启，以重新生成
  私有配置；无需手动迁移配对或修改外部 Provider 凭据。
- 手机端验证：838 项通过、1 项原有跳过；最终缩略图样式通过 10 项定向测试。
  认证后续修复通过 380 项相关测试。
- macOS 睡眠/空闲后的 Keychain 弹窗仍需用户原生实机复测，Linux 测试不能
  替代该验收。Windows 保持 beta 及既有依赖要求。仅支持 OpenAI 协议的端点
  不会因此自动兼容 Claude 协议。
