# v8.6.7

Released: 2026-08-16

## English

### Highlights

- Added the first CCB Desktop API v1 contract slice for a future macOS desktop
  client: project-scoped discovery, same-UID Unix descriptor validation,
  handshake, snapshot, supported job events, generation recovery, and action
  receipts.
- Added fail-closed authority checks for project root, UID, permissions,
  protocol version, event capability, and request scope. Unknown or stale
  generations do not silently mutate desktop state.
- Preserved the existing API v2 path and kept Desktop API behavior isolated from
  the existing CLI and Mobile release surfaces.

### Verification

- Focused Desktop API contract tests: `25 passed`.
- macOS universal release artifact and packaged runtime/native-helper smoke:
  passed.
- This release does not claim a bundled CCB Desktop application, Rust/Tauri
  integration, signing/notarization, or a compatibility promise for an
  installed Desktop client.

### Upgrade notes

- No existing CCB configuration, pairing, workspace, or conversation migration
  is required.
- Desktop clients must negotiate the versioned Desktop API contract and fail
  closed when the CCB release does not advertise the required capability.

## 中文

### 版本亮点

- 新增面向未来 macOS 桌面端的首个 CCB Desktop API v1 契约切片：项目范围
  discovery、同 UID Unix descriptor 校验、handshake、snapshot、受支持的
  job 事件、generation 恢复和 action receipt。
- 新增项目 root、UID、权限、协议版本、事件 capability 和请求范围的
  fail-closed 校验；未知或过期 generation 不会静默修改桌面状态。
- 保留既有 API v2 路径，并将 Desktop API 行为隔离在现有 CLI 与 Mobile
  发布面之外。

### 验证结果

- Desktop API focused contract tests：`25 passed`。
- macOS universal 发布制品以及打包 runtime/native helper smoke：通过。
- 本版本不宣称包含完整 CCB Desktop 应用、Rust/Tauri 集成、签名/公证，或
  已安装 Desktop 客户端兼容承诺。

### 升级说明

- 无需迁移现有 CCB 配置、配对信息、workspace 或对话历史。
- Desktop 客户端必须协商版本化 Desktop API 契约；当 CCB release 未声明所需
  capability 时必须 fail-closed。
