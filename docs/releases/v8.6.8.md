# v8.6.8

Released: 2026-08-17

## English

### Highlights

- CCB Mobile now provides an adjustable content-surface opacity for local
  workspace backgrounds. The selected image also extends across the project
  list and workspace chrome while controls retain readable surfaces.
- Expanded long replies open at their internal bottom and remain visible at the
  latest timeline position. Downloadable files are rendered as normal content
  inside the message bubble instead of occupying a floating outer region.

### Fixes and reliability

- Short messages with attachments keep their natural height, while long
  collapsed messages reveal attachments only after expansion and keep them in
  the same internal scroll viewport as the message body.
- Native Windows process readers replace undecodable subprocess bytes instead
  of failing. Herdr launches now return pane-state authority to native
  detection and expose Provider processes as the foreground command.
- Retired Agent state cleanup is deferred while its runtime is still alive or
  files remain in use, then retried from a persisted marker. This release
  integrates the remaining functional changes from PR #314, formally merges
  PRs #315 and #317, and supersedes PR #316 with a corrected cross-platform
  process-liveness mock.

### Upgrade notes

- Upgrade the CCB host and CCB Mobile APK to `v8.6.8` together. No pairing,
  conversation, project, or configuration migration is required.
- Existing background selections remain local to the device and retain the
  default opacity until adjusted in settings.

### Known limitations

- Android is the validated Mobile release target; iOS/iPadOS remain
  source-supported. Native Windows x64 and Herdr support remain beta.

## 中文

### 版本亮点

- CCB Mobile 为本地工作区背景新增内容表面不透明度调节。所选背景图现在也覆盖项目列表
  和工作区外壳，同时控制界面继续保留清晰可读的内容表面。
- 展开较长回复时会直接定位到气泡内部底部，并让最新气泡保持在时间线可见位置。可下载
  文件改为气泡内的普通消息内容，不再悬浮在气泡外占用额外空间。

### 修复与稳定性

- 带附件的短消息保持自然高度；较长消息折叠时隐藏附件，展开后附件与正文位于同一个内部
  滚动区域。
- 原生 Windows 进程读取遇到不可解码的子进程字节时会进行替换，不再直接失败。Herdr
  启动会把 Pane 状态判断权交回原生检测，并让 Provider 进程成为可识别的前台命令。
- 退役 Agent 的运行时仍存活或文件仍被占用时，状态清理会延后并记录持久标记，随后自动
  重试。本版本集成 PR #314 的其余功能改动，正式合并 PR #315 与 #317，并用修正后的
  跨平台进程存活 mock 取代 PR #316。

### 升级说明

- 请将 CCB 主机和 CCB Mobile APK 一起升级到 `v8.6.8`。无需迁移配对信息、对话、
  项目或配置。
- 现有背景图仍只保存在当前设备；用户在设置中调整前会继续使用默认不透明度。

### 已知限制

- Android 是经过验证的 Mobile 发布目标；iOS/iPadOS 仍为源码支持。原生 Windows x64
  与 Herdr 支持仍处于 beta 阶段。
