# v8.7.11

Released: 2026-10-13

## English

### V2 workflow compatibility

- Ordinary V2 Frontdesk → Executor → Workers projects can submit normal or silent asks without a Planner or activation-style task ID. Agent names alone no longer enable the V3 agentic-loop workflow.
- Gate Frontdesk/Detailer handoffs, startup journal recovery and Frontdesk completion checks on the loaded project's explicit workflow configuration. Old workflow journals cannot replay tasks into a V2 project; opted-in V3 workflows retain their strict checks.

### Pi request attribution and cancellation

- Include PR #385: retain request attribution when image processing transforms Pi prompt input but preserves request and dispatch headers, preventing affected completions from remaining stuck in running state.
- Scope Pi cancellation to the exact active request. Unrelated native input and other requests no longer receive Escape from a stale cancellation.
- Preserve digest matching, legacy persisted jobs, raw no-wrap input and OMP compatibility.

### Community and upgrade notes

- Refresh the WeChat technical group 2 QR image and README cache identifiers using the owner's replacement image, valid until October 20.
- Upgrade CCB and safely reopen affected projects to load the updated daemon and projected Pi extension. No project configuration or conversation migration is required. Desktop, npm and mobile version metadata are synchronized; no new mobile UI behavior is included.
- Dispatcher/storage and actual generated-extension replay regressions were verified. An authenticated Pi model roundtrip using transformed image input is not qualified by this release verification. Local repairs of overwritten development launchers are host maintenance, not a new installer feature.

## 中文

### V2 工作流兼容性

- 普通 V2 Frontdesk → Executor → Workers 项目可正常发送普通或静默 ask，无需 Planner 或激活格式的任务 ID。代理名称本身不再触发 V3 agentic-loop 工作流。
- Frontdesk/Detailer 交接、启动日志恢复和 Frontdesk 完成检查均以已加载项目的显式工作流配置为准。旧工作流日志不会向 V2 项目重放任务；显式启用 V3 工作流时仍保留严格检查。

### Pi 请求归属与取消

- 包含 PR #385：图片处理改变 Pi 提示正文但保留请求和派发标识时，仍能正确识别请求归属，避免受影响的任务已完成却持续显示 running。
- Pi 取消操作仅对准确匹配的当前活动请求发送 Escape，过期取消不会干扰其他请求或原生输入。
- 保留摘要匹配、旧版持久化任务、原始 no-wrap 输入及 OMP 兼容性。

### 社区与升级说明

- 使用项目所有者提供的新图片刷新微信技术群 2 二维码及 README 缓存标识，图片标注有效期至 10 月 20 日。
- 更新 CCB 后，在可以安全中断工作时重新打开受影响项目，以加载新版 daemon 和投影的 Pi 扩展。无需迁移项目配置或对话。桌面、npm 与手机端版本元数据同步；不包含新的手机界面行为。
- 已验证 dispatcher/storage 回归及实际生成扩展的事件重放。本次发布验证不包含经过身份认证的 Pi 模型图片转换往返测试。本机被覆盖的开发命令入口修复属于主机维护，不代表新增安装器功能。
