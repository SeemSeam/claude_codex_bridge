# v8.7.13

## English

### OMP Mobile: Linux Collab integration

- Linux OMP agents attach Mobile to the existing native TUI through a private loopback Collab relay. Native snapshots, live output, reasoning, tool calls and results are grouped into user-anchored reply bubbles.
- Preserve exact ancestry when upstream Collab omits metadata entries. Cross-launch unique submission keys avoid collisions; retries retain the original key. Uncertain prompt admission is not presented as successful execution and is never automatically replayed.
- Select the current native model and supported thinking level from Mobile. Changes use the same host/session, require idle/draft and revision guards, and confirm native readback without changing project configuration or restarting the agent.
- Pause selected-agent refresh in the background; show explicit disconnect/reconnect state. Bound local transport memory and clean up the supervised process group on exit.

### Compatibility and upgrade

- **New Collab routing is Linux-only. macOS keeps the original OMP terminal-input/native-history route.** Mobile follows the server-advertised capability, not the provider name alone. Other Provider routes remain unchanged.
- Update both CCB and Mobile. Normally restart idle Linux OMP agents when safe to load the new supervisor; existing sessions are not forcibly interrupted. Mac does not require the Collab supervisor.
- Synchronize desktop, npm and Mobile version identity (Android versionCode 8070013), including the in-app update fallback and download entry.

### Verification scope

- Flutter full regression: 857 passed, one skipped; static analysis clean. Gateway/OMP routing regression: 231 passed, two skipped; Bun protocol/model regression: 13 passed; actual Linux OMP TUI model/readback/shutdown smoke passed.
- Android API 35 exercised live/durable turns, tool folding, same-session model selection, stale fences, disconnect/reconnect and background suspension. A separate current-project paid-model request read real files and exposed the ancestry issue, whose original result was recovered without replay.
- macOS legacy routing is covered by platform-simulated contracts, not a new macOS hardware acceptance claim. Android deterministic fixtures do not establish paid-model quality. Interactive approvals and remote session branching are not included.

## 中文

### OMP 手机端：Linux Collab 接入

- Linux OMP 通过私有本机 Collab Relay 连接现有原生 TUI，快照、实时正文、推理、工具调用和结果按用户回合聚合为对话气泡。
- 修复上游省略元数据造成的祖先断链；新请求使用跨启动唯一幂等键，重试保留原键。准入不确定时明确展示，不自动重放请求。
- 手机端可选择当前原生模型及支持的思考等级；同宿主、同会话操作，校验忙闲、桌面草稿和运行版本，读回确认生效，不改项目配置、不重启 Agent。
- 后台暂停当前 Agent 刷新；显式展示断连与重连，限制传输内存，退出时回收受管进程组。

### 兼容与升级

- **仅 Linux 开放新 Collab 路由；Mac 保留原 OMP 终端输入和原生历史路由。** 手机依据服务端能力声明分流，其他 Provider 接入方式不变。
- CCB 和 Mobile 一并更新；Linux OMP 请在任务空闲且安全时正常重启以加载新 supervisor，不强制中断已有会话。Mac 不启动 Collab supervisor。
- 同步桌面、npm、Mobile 版本号（Android versionCode 8070013），修正应用内版本回退值和下载入口。

- Flutter 全量 857 通过、1 跳过，静态分析无问题；网关/OMP 路由 231 通过、2 跳过；Bun 协议/模型 13 通过；Linux 真实 TUI 模型切换读回和退出烟测通过。
