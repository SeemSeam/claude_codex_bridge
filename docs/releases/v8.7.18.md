# v8.7.18

## English

### Stable OMP Mobile connections and complete history

- Keep an authenticated healthy Collab connection alive when a history query fails. Report history and connection failures separately instead of repeatedly closing/rejoining as `collab:1` / `collab:2`.
- Replace whole-session ancestry export and its 16,384-entry ceiling with indexed native parent-chain pages, bounded to 128 records / 256 KiB. Signed cursors are owner/session/branch-fenced and remain valid across appends; genuine branch changes reject stale cursors.
- Retain at most 512 recent entries / 4 MiB in the live bridge while consuming the native snapshot barrier. Older history is read on demand, not lost when the recent replica evicts it. Oversized records use lossless byte chunks; complete turns preserve intermediate prose, tool calls and results.
- Preserve loaded phone pages and disclosure state across same-branch refreshes. Fence cross-transport append races so stale pending/stream metadata cannot duplicate an already durable input.

### Readable, bounded reply bubbles

- Oversized replies display structured recent content directly in the bubble rather than only a 512-character prefix and a raw original-content link.
- Bound each serialized inline item, including its original-content cursor, to 24 KiB, at most 8 entries / 24 blocks. Prioritize latest assistant prose (up to 8,000 Unicode characters, reduced by the actual byte budget); recent process snippets are limited to 1,500 characters per block.
- Replace the bounded window within the same bubble on refresh rather than accumulating stale windows. Keep normal full-turn merging unchanged. Oversized user inputs retain a readable bounded tail. Original content and its hash remain unchanged and separately pageable.

### Verification and upgrade

- Local Android API 35 emulator, actual OMP 18.12.6 native host, generated bridge, production gateway and encrypted Relay passed long-history and readable-bubble scenarios. The fixture contained 28,702 records, a 19,001-entry metadata gap, 141,678,063 raw history bytes and 63,257,173 replicated message bytes. All 200 initial conversation items were traversed; the 987,082-byte Unicode/tool original matched its SHA-256 after 31 content pages.
- Verified history failure/recovery without extra join/leave notices, append-safe replay, genuine branch isolation, FIFO, and same-bubble live tail replacement. No paid model requests. Actual OMP PTY reply-receipt smoke also passed after the history bridge changes.
- Release qualification: 285 targeted Python regressions, 21 runtime tests and 62 targeted Flutter tests passed; Flutter analysis reported no issues, npm pack verification passed, and actual OMP PTY receipt smoke passed. These are exercised selections, not a claim that the entire repository suite was run.
- Update server and Android app together. Already-running OMP extensions need a normal restart when idle; do not interrupt busy Agents or clear history to upgrade. The legacy macOS route and other Provider routes are unchanged; Windows remains beta. Existing pairing is preserved by the managed Mobile gateway restart.
- The emulator scenarios use isolated fixtures, not a claim that every phone/network or live project has been qualified. The local modified gateway was separately installed and restarted for owner testing; no formal release tag was previously published for those source changes.

## 中文

### 稳定连接与完整历史

- 历史查询失败不再关闭健康的 Collab 连接；区分历史数据错误和连接错误，避免 `collab:1` / `collab:2` 反复跳动。
- 全量 ancestry 导出及其 16,384 条上限改为原生索引父链分页，每页最多 128 条 / 256 KiB。签名游标绑定宿主、会话及分支，支持同分支追加；真实分支变化时拒绝旧游标。
- 实时桥最多保留 512 条 / 4 MiB 近期记录，并正常消费原生快照结束屏障；旧历史按需读取，不因近期缓存淘汰而丢失。超大记录分块无损传输，完整回合保留中间正文及工具调用、结果。
- 同分支刷新保留手机已加载旧页和展开状态；修复原生历史先于实时快照到达时，旧待发/流式信息造成重复输入的竞态。

### 有上限的可读对话泡

- 超长回复直接显示最近的结构化正文与执行信息，不再只有开头 512 字符和原始 JSON 阅读入口。
- 单项包含原文游标的序列化内容不超过 24 KiB，最多 8 条记录 / 24 个块；优先保留最新正文，最多 8,000 个 Unicode 字符，实际字节预算不足时缩短；过程单块最多 1,500 字符。
- 同一气泡刷新替换最新窗口，不累积旧窗口；普通完整回合的合并保持不变。超长用户输入显示有界尾部，完整原文与哈希保持不变，仍可另外分页读取。

### 验证与升级

- 本地 Android API 35 虚拟机结合真实 OMP 18.12.6 原生宿主、生成桥、生产网关和加密 Relay 验收通过。夹具包含 28,702 条记录、19,001 条元数据间隔、141,678,063 字节原始历史、63,257,173 字节实际复制消息；初始 200 条对话项全部遍历，987,082 字节 Unicode/工具原文经 31 页读取后 SHA-256 一致。
- 历史错误恢复无额外 join/leave、追加后旧页重读、真实分支隔离、FIFO、同气泡最新尾部替换均通过；零付费模型调用。历史桥变更后的真实 OMP PTY 回执烟测也通过。
- 发布门禁：285 项针对性 Python 回归、21 项运行时测试、62 项 Flutter 测试通过，Flutter 静态分析无问题，npm 打包检查和真实 OMP PTY 回执烟测通过；不冒称执行了仓库全量测试。
- 服务器和 Android 应用一起更新；已有 OMP 扩展需在空闲时正常重启加载，不中断忙碌 Agent，也不清空历史。Mac legacy 与其他 Provider 路由不变，Windows 仍为 beta；受管 Mobile 网关重启保留配对。
- 虚拟机验收使用隔离夹具，不等于所有手机、网络或真实项目均已验收。本地修改网关此前另行安装重启供用户测试，这些源码变更此前未发布正式标签。
