# v8.7.19

## English

### OMP Mobile native questions and runtime status

- Render native Collab select/editor questions as separate interactive cards, with descriptions and custom text input. Answers use `ui-response`, not ordinary chat prompts, over HTTP or encrypted Relay.
- Fence answers to namespace, native session, generation and request ID. Clear ended/disconnected requests; uncertain sends are not automatically retried. Pending questions prevent ordinary prompts from draining through the dialog.
- Show bounded native runtime metadata: elapsed time, current step, queue depth, model/thinking/context usage, task progress and Todo counts. Missing evidence stays unavailable rather than being inferred from prose or terminal rendering.
- Show running status inside the current working reply bubble without repeating it above the timeline. Preserve assistant prose and remove misleading unfinished/no-answer placeholders.

### Readable content and reliable attribution

- Replace raw JSON original-content pages with a full-screen semantic Markdown reader. Reasoning and tools fold independently; Unicode-safe pages retain immutable version/branch fences and exact source blocks.
- Replace the mobile Tab shortcut with the Codex Queue action, preserving user drafts and uploaded attachments.
- Keep Pi/OMP completion tracking bound to the parent session through in-process subagent turns; subagent events no longer supersede the parent request or leak into its reply.

### Verification and upgrade

- Exercised before release preparation: 154 targeted Python tests, 40 Bun runtime tests and 91 targeted Flutter tests passed; Flutter analysis reported no issues. A real OMP 18.12.6 CollabHost completed select/editor responses with zero model calls. Android API 35 exercised actual option selection and editor submission in an isolated application surface.
- These are targeted checks, not a full-suite or every-device qualification claim. The Android card smoke and native host smoke are separate checks, not a claim of one combined live-project network scenario.
- Upgrade the server gateway and Android app together. Existing OMP processes load the bridge after a normal restart when idle. Do not interrupt busy agents or clear history. Unsupported/oversized dialogs still require desktop interaction. Windows remains beta.

## 中文

### OMP 手机原生交互与运行状态

- Collab 原生选择/编辑问题显示为独立交互卡片，支持选项说明及自定义输入。通过 HTTP 或加密 Relay 返回原生 `ui-response`，不再作为普通聊天消息排队。
- 使用命名空间、会话、代次和请求编号防止旧答案误投；请求结束或断线清除待答状态，发送结果不明时不自动重试。原生对话待回答期间不继续派发普通排队消息。
- 展示有界原生状态：运行时间、当前步骤、队列深度、模型/思考等级/上下文用量、任务进度及 Todo 数量。缺失证据保持不可用，不从正文或终端文字猜测。
- 正在运行的状态放在当前回复气泡内，不在时间线上方重复显示；保留助手正文，去掉误导性的“工具未完成/无回答”占位。

### 内容阅读与回复归属

- 原始 JSON 页改为全屏语义 Markdown 阅读器，思考和工具独立折叠；Unicode 安全分页保持不可变版本/分支边界及精确源文本。
- 手机 Tab 快捷键改为 Codex Queue 操作，保留草稿与上传附件。
- Pi/OMP 请求绑定在进程内子代理回合期间仍归属父会话，子代理事件不再覆盖父请求或混入父回复。

### 验证与升级

- 发布准备前已执行：154 项针对性 Python 回归、40 项 Bun 运行时回归、91 项 Flutter 回归通过，Flutter 静态分析无问题。真实 OMP 18.12.6 CollabHost 选择/编辑回复通过，零模型调用；Android API 35 隔离界面实际点选与编辑提交通过。
- 以上不是仓库全量测试或所有设备验收；Android 卡片与原生宿主分别验证，不冒称一次完整真实项目网络联调。
- 服务端 gateway 和 Android App 一起升级；已有 OMP 空闲后正常重启加载桥接，不中断忙碌 Agent，不清空历史。超出有界限制的对话仍需桌面处理；Windows 继续作为 beta。
