# v8.7.20

## English

- Integrate PR #400: chat bubbles and content readers use one selectable `CcbMarkdown` widget backed by `gpt_markdown` 1.3.4.
- Add syntax-highlighted fenced code with language labels and copy controls, task-list checkboxes, and LaTeX using `\( … \)` / `\[ … \]`. Dollar-delimited math is not enabled.
- Preserve artifact actions, external-link confirmation, blocked unsupported schemes, and app-themed Markdown colors.
- Pin below 1.4.0 to retain compatibility with Flutter Material themes. Raise the declared Dart floor to 3.9 and regenerate dependencies with the release SDK, Flutter 3.44.2, removing seven unrelated dependency upgrades.
- Include the mounted-Agent hibernation proposal and isolated prototype evidence; automatic production hibernation is not implemented by this release.
- Known display limitation: task-list checkboxes retain extra bullet/vertical spacing. Targeted reader, bubble and composer verification passed 98 tests during integration. Isolated narrow-width Markdown smoke covered code, long tables, links, math, task lists and quotes; this is not a new Android gateway/Relay end-to-end qualification.
- Update the Android app to receive the renderer change. Windows remains beta. No busy Agent restart or history reset is required for this app renderer update.

## 中文

- 集成 PR #400：聊天气泡和内容阅读器统一使用可选择文本的 `CcbMarkdown`，底层为 `gpt_markdown` 1.3.4。
- 围栏代码支持语法高亮、语言标签和复制按钮；增加任务列表复选框及 `\( … \)` / `\[ … \]` LaTeX 渲染，不启用美元符号公式。
- 保留文件操作、外链确认、非支持协议拦截与应用主题颜色。
- 固定低于 1.4.0，避免独立 Material 库与应用主题不兼容。Dart 声明下限调整为 3.9，使用发布 SDK Flutter 3.44.2 重整锁文件，撤销七项无关依赖升级。
- 同时收录 Agent 休眠方案与隔离原型证据；本版本不宣称已实现生产自动休眠。
- 已知显示限制：任务列表仍有额外圆点和较大间距。集成时阅读器、气泡、composer 共 98 项针对性测试通过；隔离窄屏烟测覆盖代码、长表格、链接、公式、任务列表和引用，不等于新增 Android gateway/Relay 端到端验收。
- 升级 Android App 获得新渲染器；Windows 仍为 beta。此应用渲染更新不需要重启忙碌 Agent 或清空历史。
