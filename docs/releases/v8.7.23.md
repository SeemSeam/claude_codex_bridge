# v8.7.23

Released: 2026-11-19

## English

- CCB-managed OMP panes disable inline terminal images by default to prevent graphics from crossing pane boundaries. Resize rebuilds terminal scrollback to avoid duplicating history. Standalone OMP, headless jobs, and tmux graphics passthrough are unchanged.
- Explicit `ccb update` provider discovery includes Bun before OMP when OMP is installed. Recognized native `.bun/bin/bun` installations use `bun upgrade` through the existing confirmation, check-only, selection and version-mute controls; unknown installation owners are report-only. Upgrades require a successful version probe. Failed OMP startup probes no longer misread dependency versions, and its installed package manifest can supply the OMP version when old Bun prevents startup.
- README introductions now lead directly to installation. Per-version details are available in the changelog and release notes.
- Upgrade with `ccb update` or `npm install -g @seemseam/ccb@8.7.23`. Existing OMP panes pick up the new display settings when CCB generates a new launch command. Wait until agents are idle before relaunching. Publishing this release does not upgrade external Provider binaries or restart running agents.
- Verified in Konsole with tmux and OMP 18.20.0: repeated window resizes, pane zoom and switching, and resizing in copy mode preserved all 65 test history markers without duplicates. Native Collab connected to the restored session. The original complete scroll lock was not reproduced.
- The retained Android VM diagnosis documents an isolated Relay/native-Collab pass; it does not qualify the reported production device/Relay incident. Windows support remains beta.

## 中文

- CCB 托管的 OMP 窗格默认关闭终端内联图片，避免图层越过分屏边界；缩放时重建终端回滚历史，避免重复。独立运行的 OMP、无界面任务和 tmux 图形透传均不受影响。
- 显式执行 `ccb update` 时，若已安装 OMP，Provider 更新检查会先列出 Bun。能够识别的原生 `.bun/bin/bun` 安装通过 `bun upgrade` 升级，沿用现有确认、仅检查、选择更新和版本静默机制；安装归属不明时仅报告。升级后须成功探测版本；OMP 启动失败时不再误读依赖版本，旧 Bun 导致无法启动时可从已安装包清单读取 OMP 版本。
- 各语言 README 的简介后直接进入安装，版本细节请查看更新日志和版本说明。
- 执行 `ccb update` 或 `npm install -g @seemseam/ccb@8.7.23` 升级。已有 OMP 窗格在 CCB 重新生成启动命令后加载新的显示设置，请等 Agent 空闲再重新启动。本次发布不会直接升级外部 Provider 程序或重启运行中的 Agent。
- 已用 Konsole、tmux 和 OMP 18.20.0 实测：反复缩放窗口、放大还原和切换窗格、在复制模式中缩放，65 条测试历史标记均无丢失、无重复；原生 Collab 成功连接恢复的会话。未复现原先的完全滚动锁死。
- 保留的 Android 虚拟机诊断记录证明隔离 Relay 与原生 Collab 回归通过，不代表已验收用户报告的生产设备或 Relay 故障。Windows 支持仍为 beta。
