# v8.7.24

Released: 2026-11-19

## English

- Linux OMP panes launched through Collab now redraw when their tmux pane changes size. The Collab supervisor forwards the terminal resize signal to OMP so streamed text reflows when you resize, zoom, or unzoom a pane.
- Upgrade with `ccb update` or `npm install -g @seemseam/ccb@8.7.24`. Existing OMP panes load the fix when CCB next launches them. Let active work finish before relaunching a pane.

## 中文

- 在 Linux 上，通过 Collab 启动的 OMP 窗格现在会随 tmux 窗格尺寸变化而重绘。Collab 监督进程会把终端缩放信号转发给 OMP，流式输出会在调整尺寸、放大或还原窗格时重新换行。
- 执行 `ccb update` 或 `npm install -g @seemseam/ccb@8.7.24` 升级。已有 OMP 窗格会在 CCB 下一次启动它们时加载修复，请等正在运行的任务结束后再重新启动窗格。
