# v8.7.25

Released: 2026-11-23

## English

- Restore automatic message delivery to Codex panes whose footer displays `← for agents · ? for shortcuts`. CCB now recognizes the new hint when checking whether the composer is empty. The check also supports the previous footer and continues to protect active turns, open menus, and unsent drafts. [PR #405](https://github.com/SeemSeam/claude_codex_bridge/pull/405)
- Upgrade with `ccb update` or `npm install -g @seemseam/ccb@8.7.25`. If the project is already running, let active work finish before restarting the CCB project to load the updated delivery check.

## 中文

- 恢复向底栏显示 `← for agents · ? for shortcuts` 的 Codex 窗格自动投递消息。CCB 检查输入框是否为空时会识别这条新提示，同时兼容旧版底栏，并继续保护正在执行的轮次、打开的菜单和未发送的草稿。[PR #405](https://github.com/SeemSeam/claude_codex_bridge/pull/405)
- 执行 `ccb update` 或 `npm install -g @seemseam/ccb@8.7.25` 升级。如果项目已在运行，请等当前任务结束后重启 CCB 项目，加载更新后的投递检查。
