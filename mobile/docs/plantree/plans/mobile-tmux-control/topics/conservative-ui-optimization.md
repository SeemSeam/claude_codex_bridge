# 手机端保守 UI 优化清单

日期：2026-09-17
状态：已本地实施、测试并安装虚拟机；未提交或发布。
依据：用户认可保守 Demo，要求保留 Terminal 窗口，仅在必要时优化快捷键折叠。
原型与自审：[保守 Demo](../../../../../design-demo/MULTI_WINDOW_REVIEW.md)。

## 范围约束

- 保留对话内窗口行、当前窗口 Agent 行、既有自动折叠与双模式切换。
- 对话为主要空间；减少留白和重复信息，不以缩小触控范围换密度。
- Terminal 布局、渲染、输入、选区、滚动及切换入口保持现状。
- 不新增 Agent 搜索、全部 Agent 页、筛选、导航、终端预览或设置项。
- 旧六页原型和 multi-window 旧提案不是实施授权；当前 conservative
  原型仅作为视觉参照，不能替换 Flutter 交互状态机。
- 已落盘的状态配色是基线，先复核再局部调整，不重复重写。

## 排序清单

| 优先级 | 区域 | 优化项 | 验收要点 |
| --- | --- | --- | --- |
| P1 | 对话顶栏 | 收紧多余间距，保留返回、配置、刷新、终端、更多的位置与含义 | 目标身份可读；既有入口与点击范围不丢失 |
| P1 | 窗口 / Agent 行 | 微调两排间距、标签内边距和文字层级 | 短名不无故截断；长名不挤掉状态；通常保留48dp点击高度，矮屏沿用已有自适应 |
| P1 | 状态显示 | 复核绿色工作、灰色空闲、红色异常、橙色未读、独立选中样式 | 选中不覆盖状态色；状态变更无残留；颜色之外有文字/语义 |
| P1 | 折叠区 | 保留原手柄和自动折叠，只调整多余留白及摘要排版 | 展开/折叠与模式切换不产生额外状态重置；手柄不得进一步缩小 |
| P1 | 消息卡片 | 微调卡片间距、内边距、正文与时间层级 | 不更改消息分组、内容折叠规则或 Markdown/代码渲染；长文与代码仍可读 |
| P1 | 输入区 | 沿用现有附件、输入、选项、发送结构，统一对齐 | 键盘不遮挡；多行输入、草稿、附件及目标切换无回归 |
| P2 | 项目首页 | 统一项目名、工作状态和连接信息的视觉优先级，收紧卡片留白 | 继续动态单机/多机显示；工作数与未读独立；不增加筛选或重新排序 |
| P2 | 既有设置 / 连接页面 | 审查并统一分组间距、标签和值的对齐、长地址换行 | 不移动功能归属、不新增设置、不改变连接流程；先对照现有页面确认具体差异 |
| 条件项 | Terminal 快捷键 | 仅评估现有快捷键栏展开/收起入口是否清晰、是否占用过多高度 | 若无实际问题则不改；需要改时保留键集合、顺序、发送语义和现有默认行为 |

## Terminal 快捷键专项边界

先在虚拟机检查键盘开/关、横/竖屏和快捷键当前展开/收起状态。
若有明显占高或难以收起问题，仅改折叠入口、触控范围和栏内留白。
不新增自动折叠策略或持久化偏好；折叠操作不得发送按键、转移终端焦点、
清空输入或重置终端连接。Ctrl 等组合键语义保持原样。

## 执行与验证顺序

1. 同一构建、同一目标和相近内容捕获虚拟机基线；确认待优化项真实存在。
2. 先实施 P1 中已明确的视觉细调，再单独处理首页及设置的小范围差异。
3. Terminal 快捷键先给出实机结论，无问题则明确保留，不为改而改。
4. 针对改动验证320px、长名、1.6倍字体、亮暗主题、键盘和矮横屏；
   检查实际几何、状态组合及工作→空闲/异常切换，而非仅查找文本。
5. 跑相关 widget 回归、analyze；正式交付前完整 Flutter suite，构建安装
   虚拟机并检查聊天/终端往返、草稿、阅读位置、折叠状态及既有菜单。

HTML 原型只作设计参考，原生验证记录见下方。
不涉及后端、Provider 管理、存储协议、Windows、发布或提交。
回退限定为本轮视觉文件差异，保留已有工作，不迁移或删除用户数据。

## 本轮落地与证据

- 聊天顶栏常规高度64→56dp，并随字体缩放增长；标题左右留白8→4dp。
  Terminal 分支保持64dp及原间距，所有入口与回调保留。
- 两排选择器间距4→2dp；保留48dp标签命中和矮屏既有自适应、32×72手柄。
  既有状态配色、未读、默认展开和自动折叠逻辑均复用。
- 消息卡片垂直内边距10→8dp，标题/时间/折叠图标垂直居中；
  输入框左右内边距统一6dp，不变更消息内容与发送行为。
- 首页当前项目、服务器项目、多主机项目卡片垂直内边距8→6dp；
  路径改用次级文字样式，项目名及工作状态更突出。
- 设置/诊断页实机检查：现有分组和长文本换行可用，本轮不改结构。
- Terminal 快捷键实机检查：默认加号收起、两行展开及关闭正常；
  暂未发现需要改动的折叠问题，因此该条件项不实施。未改变终端代码。
